# log28 分析（PID 首测：~2 秒遇左弯即飞、一直打转）

> 背景：首次切 PID 跑弯道。用 `pid-default` 档，**speed=15, kp=80, ki=0, kd=15, slew=5000, lograte=10**（base≈96）。跑约 22s（前 2s 正常，之后飞出去打转，被手动停）。

## 一、经过（解码丢线前那一下）
前 ~2 秒是**正常的**：车在 CH4 附近、err 小（-0.1 上下）、PWM ~90/100 轻修，PID 直行段跟得很好。
然后遇到一个**左弯**，线快速往左扫，PID 一路加大左转，最后冲过头丢线：
```
pattern:  60 → E0 → C0 → 80 → 00(丢)     (CH6+7 → +CH8 → CH7+8 → CH8 → 全丢, 线扫出左边)
err:    -0.50 -0.65 -0.79 -0.87 -0.91 → 丢
pwm L/R: -16/208  -34/226  -18/210  -18/210  -23/215     ← 右轮(外)飙到 200~228，左轮(内)反转 ~-25
line260: E1981 00 A -19 205 +0.00   ← 丢线(LOST_L)，之后一直左转找线、找不回
```
- PID 方向没错（在猛烈左转：右轮 forward ~215、左轮 reverse ~-25）。
- 丢线后 LOST_L 持续找线 ~9 秒（thrash/打转，偶尔碰到线又丢），最终 1500ms 超时 → LOST_STOP，停车坐了 8.5 秒（`00 C` 849 行）到你按停。**"一直打转"就是这段左转找线。**

## 二、⭐根因：PID 把"外轮"顶上天，加速冲进弯 → 过冲丢线
关键在 `pwm_l = base + 输出，pwm_r = base − 输出`。左弯时 err 大负、输出大负：
```
line250: pwm_r = base − 输出 = 96 − (−130) = 226   (= 2.4×base，逼近上限255!)
```
- **外轮(右)被顶到 226**——车**一边猛左转、一边把前进速度拉到 2 倍多**，动能巨大，**直接冲过左弯的半径**，线还没等 pivot 掰回来就扫出了左边缘 → 丢。
- 对比 bang-bang：外轮**最多 base、急弯还 turn_ratio 降速**，绝不会加速冲进弯。**PID 这个对称公式恰好相反——越要转，外轮越快。** 这就是 PID 一个左弯就飞、而 bb 能跑几十秒的直接区别。
- **kd=15 火上浇油**：line250 输出 −130 里，P 项只占 80×(−0.65)=−52，剩下 −78 是 **kd 项**——err 从 −0.5 快速冲到 −0.9 时微分尖峰，把外轮顶得更高。

## 三、次要：还是"偏左"
LOST 占比 45%，其中 **LOST_L=974、LOST_R=56**——几乎全在左侧丢。和 log26/27 一样的系统性左偏，PID 下更致命（左弯直接飞）。

## 四、结论与建议
**不是 PID 不行，是"外轮被 output 顶上天、加速冲弯"这个结构问题。** 要让 PID 能跑弯：

1. **⭐结构性修复（改代码，最关键）**：让 PID 输出只**减内轮、不加外轮**——把两轮 PWM **封顶在 base**（`pwm = min(base, base±output)`），或**按 |err| 降 base**（弯道降速，同方案A）。这样急弯只会"内轮反转+外轮≤base"，不再加速冲弯。**这条不修，纯 PID 很难跑过急弯。**
2. **降速**：speed 15→12/13，base 小了绝对过冲也小。
3. **降 kd**：15→5~8，减少 err 快变时的微分尖峰（别让它把外轮顶更高）。
4. **kp 视情况**：现在 kp=80 内轮只到 16（不反转），发卡本就偏弱；但在"外轮封顶"之前先别加 kp，否则外轮顶得更狠。等封顶了再把 kp 提到能反转内轮（~120-140）。
5. **查左偏**：LOST 几乎全左，先确认左右轮/标定是否对称（见 `log26-27分析.md` 第四节）。

## 五、下一步顺序
建议：① 先改代码把 PID 的外轮封顶在 base（或按 err 降 base）；② speed 12、kp 80、kd 6 重试；③ 再逐步提 kp 到能过发卡。否则光调 kp/kd，外轮 boost 的结构问题还在，还会一遇急弯就飞。
