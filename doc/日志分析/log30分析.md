# log30 分析（PID kp130/kd6：过转变差 + 左偏成主因）

> 背景：log29 判断"欠转"后，把 **kp 80→130、kd 15→6** 重跑。参数：PID speed15, kp130, ki0, kd6, slew5000（base≈96）。用户反馈：**效果变差了。**

## 一、确认：变差了
| | log29 (kp80) | **log30 (kp130/kd6)** |
|---|---|---|
| 时长 | 80s | **16s** |
| LOST 占比 | 29.8% | **52.3%** |
| LOST_L / LOST_R | 1566 / 882 | **804 / 66** |
| 外轮封顶 | 96 | **96（仍生效）** |

外轮封顶继续有效（pwm 最大 96），但**跑得更短、丢线率翻倍**。kp=130 调过头了。

## 二、直行没问题，问题全在弯道（过转）
看直行段（err 小）：`... 87 96 -0.08 → 94 96 -0.04 → 96 96 -0.02`，**平顺收敛、无振荡**。所以 kp130/kd6 在直道上是稳的。

问题在急弯：kp=130 太猛 →
- 边缘(err≈-0.9)时 output≈-117，内轮 = 96 + output 一路压到 **-109（狠狠反转）**，外轮封顶 96。
- 差速 205 ≈ **几乎原地猛掰**——急左弯时**过转/over-pivot**，一下掰过头、线甩出去 → 丢。
- 和之前对比：kp80=**欠转**(内轮只到16、跑宽丢线)；kp130=**过转**(内轮-109、掰过头丢线)。**甜点在两者之间。**

## 三、"左偏"是赛道几何，不是车的毛病（重要更正）
> 更正（据用户说明）：**赛道是操场型跑道，只往一个方向拐弯——全是左弯。**

所以 LOST_L=804、LOST_R=66（92% 在左）**完全正常**：赛道就只有左弯，右弯几乎没有，丢线自然全在左侧。**这不是"系统性左偏/左右轮不对称"，是赛道只有一种弯。** 之前 log26-30 反复说的"偏左"也应按此重新理解——不需要去查左右轮/传感器对称性（那条建议对这条赛道不成立）。
- 真要排除车本身的左右不对称，得在**直道**看是否跑偏、或**反向跑一圈**对比；但当务之急不是这个。
- 结论：**问题就是"（左）弯道过不好"**——即一直在说的转向力度/速度问题，不是对称性问题。

## 四、建议（回到弯道调参）
1. **kp 回退到中间**：80(欠转) 和 130(过转) 之间，试 **kp 100~110**；kd 回到 **10** 左右（直道稳、弯道给点阻尼）。这是当前最该做的。
2. **可再降速**：speed 15→12/13，欠/过转的绝对幅度都变小、更好调。
3. 既然只有左弯，可专门针对左弯半径调（不用担心右弯）。
4.（可选，排除车本身不对称）直道看是否跑偏；不急。

## 五、结论
- 外轮封顶（问题02 方案A）**依旧对**，不飞了、直道稳。
- kp 从 80 跳到 130 **过头了**：欠转 → 过转，中间 **kp 100~110、kd 10** 才是甜点。
- "丢线全在左"是**操场跑道只有左弯**导致的，不是车的对称性问题——**专注把（左）弯道的转向力度/速度调到位即可**。
