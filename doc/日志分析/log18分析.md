# log18 数据分析报告（方案A第一版，三档速度均 0.85，无 minpwm）

> 背景：弯道测试。此 log 用的是**方案A 第一版代码**（加 minpwm 之前），且三档速度系数都被设为 **0.85**。
> 从 config 可确认：`medium_speed=0.85, sharp_speed=0.85, hairpin_speed=0.85`，**无 `min_move_pwm` 字段**（说明是 minpwm 那次改动之前抓的）。
> 参数：speed=17, algo=BANGBANG, medium_ratio=0.65, sharp_ratio=-0.20, xsharp_ratio=-0.60, **medspeed/shpspeed/hpspeed 全 0.85**, slew=5000。运行 **40.9 秒 / 467 行**。

## 一、结论：方案A（均 0.85）没解决问题，仍在同一个"每弯必险"的坑里

- 跑了 41s，全程 `LOST_L/LOST_R`（`00 A`/`00 B`）出现 **50+ 次**——和 log17 一样，**每个急弯都"丢线→反转找线→勉强找回"**。
- 最后仍在一个**发卡弯**处猛掰失败、冲进全白区（`FF`）丢线停车（行 443–478）。**失败模式和 log17 完全相同。**
- 结论：**均匀 0.85 的降速太轻、且来得太晚，没能改变结局。**

## 二、方案A（0.85）实际把速度降到了哪

三档都 0.85 时，各档外轮（前进轮）实测：

| 档 | 外轮目标 = base×speed×turn_outer | 日志实测 | 对比 log17(无方案A) |
|---|---|---|---|
| SHARP/HAIRPIN | 108×0.85×0.65 ≈ **59** | 行76/380 `... 7 -54 59`、行97 `60 5 49 81` | log17 是 70，**这次更慢(59)** |
| MEDIUM 外轮 | 108×0.85 ≈ 91 | 行72 `30 3 98 98`(slew中) | 略慢 |

所以**弯道确实比 log17 慢了一点（外轮 59 vs 70）**，但：
1. **降速只在"已经进了弯档"之后才生效**，车还是以接近直线的速度冲到弯的边缘，才开始降——**太晚了**，overshoot 已经发生。
2. 59 的外轮**已经低于电机"运动中不失速"的 ~70**（这正是后来加 `minpwm` 的原因），弯道里可能发绵/接近堵转，反而不利于干脆过弯。

## 三、⚠️ 重要：这版代码把发卡内轮的掉头力度也削弱了

方案A 第一版对**内轮反转也乘了速度系数**，导致发卡掉头力度下降：
- 日志发卡内轮：`base_hp × xsharp_ratio = (108×0.85)×(-0.6) ≈ **-55**`（行380 `C0 7 -54 59` 实测 -54 ✓）。
- 而无方案A（log17）发卡内轮是 `108×(-0.6) = **-64**`。

**内轮反转从 -64 弱到 -54，发卡掉头更没劲**——这会让本就勉强的发卡更容易转不过来、冲出去。这是第一版的一个副作用。

> **我后来的 minpwm 版（第二版，你还没 flash）已经修正了这两点**：① 外轮加 70 地板防堵转；② sharp/发卡内轮反转**恢复用满速 base**（-64），掉头力度不再被削弱。所以第二版在发卡上应该比 log18 更有劲，值得 flash 后对比。

## 四、最后冲出的经过（行 443–478，仍是发卡thrash-off）

```
80 7(发卡左) → 00 A(丢) → C0 7 猛掰 → C0/40/C8/C1 在CH8/CH7区高频反转乱掰(-28/-44/-54)
→ FF(8路全白=冲出赛道) → 00 B → 00 C LOST_STOP
```
和 log17 一模一样：**发卡弯没转过来 → 丢线 → 盲目大幅反转找线越掰越乱 → 甩出赛道。** 这是反复要命的同一个点。

## 五、诊断：为什么方案A没救回来

1. **降速太晚**：只在进入弯档后才降，车已带着直线动能冲到弯边缘。真正需要的是"进弯前/线一离中心就收速"，而不是到了 SHARP/HAIRPIN 才降。
2. **降速太轻 + 电机死区顶着**：均 0.85 只降 15%，且外轮再低就要堵转（59 已经偏低），**没有下探空间**——这是电机死区的硬限制。
3. **第一版削弱了发卡内轮**（-54 vs -64），掉头更没劲。
4. **发卡的盲目找线仍在**：丢线后大幅反转赌方向，赌错就飞——最后就是这么飞的。

## 六、下一步建议

1. **先 flash 第二版（带 minpwm 的代码）重测**：外轮有 70 地板不堵转、发卡内轮恢复 -64 力度。用**差异化系数**（如 medspeed 85 / sharpspeed 70 / hairpinspeed 60）而不是均 0.85，看发卡是否更利索、`00 A/B` 是否下降。
2. **但别对方案A期望过高**：电机死区把外轮卡在 ~59–70，降速空间就这么点，方案A顶多压一点 MEDIUM。**"太快冲进弯"的根子仍是死区/齿轮比（硬件）。**
3. **弯道真正的解法还是 PID（提高 kp）或降齿轮比**：见 `log分析/log17分析.md` 第五节、`如何判断当前有没有机械延迟.md` 第六/七节。
4. **发卡的盲目找线要治**：丢线找线别再用大幅反转赌方向（这是每次飞出去的直接原因）。

## 七、一句话

方案A（均 0.85、第一版）把弯道外轮降到 ~59，比 log17 略慢，但**降速太晚太轻、还削弱了发卡内轮**，最终仍在发卡弯 thrash-off 冲出，和 log17 同一个坑。**先 flash 带 minpwm 的第二版、用差异化系数重测**；但根子在电机死区/硬件，方案A救不了大局，弯道还得靠 PID(高kp)或降齿轮比。
