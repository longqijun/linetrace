## 二、阶段① BB（log22-27）：查卡顿 + 试速度

### 共同背景
一套**激进、弯道零降速**的 BB 参数贯穿全程：
```
turn_ratio=1.00 (急弯外轮不降速)  sharp_ratio=-0.40  xsharp_ratio=-0.60
medspeed=0.90  shpspeed=1.00  hpspeed=1.00 (方案A弯道降速全关)
minpwm=70  slew_rate=50000 (不平滑)
```
→ 全是"冲"的方向、弯道一点没收速 → 必然 ~20% 高丢线、没裕量。

### 逐条要点
- **log22**：speed16。跟 log21 同代码同赛道，一个跑13圈一个跑4圈 → 证明**临界稳定系统结局靠运气**（起跑位置、电池电压、抓地累积）。
- **log23**：`bb_fast` speed17。~10圈后**冲进大白区(FF)约1.4s盲走** + 右侧丢线 + **盲目找线1500ms超时**→STOP。翻车位置/形式随机。**cross 修复确认有效**（整趟 CROSS 仅 5 次，都是真横杠）。
- **log24**：加 `lograte10` 首测，**暴露真问题——loop 周期性卡顿**：约每1~2秒一次、50~211ms 两条心跳间 loop 没执行；直行时也卡→与车无关，**外部任务(疑 WiFi/系统任务)抢占 loop**。卡顿期间控制冻结、车盲跑几十~两百 ms，是控制不稳的**隐藏推手**（500ms 心跳时被完全掩盖）。
- **log25**：**卡顿修复后首测**（去掉 `out()` 里持续 flash 写，问题01）。**卡顿彻底消失**：9138条心跳全是10~11ms、0次大间隔。顺带**前98s一次没撞停**（实际跑150s）——连续控制让 near-loss 都救回来了。
- **log26/27**：算法管理器做 **speed 18 vs 19 A/B**。**18(19.6%)比19(22.0%)稳**：越快发卡越多、直行越少、丢线越多。两趟前97s都无撞停，卡顿修复在18/19下继续零间隔。

### 阶段① 结论
1. **cross 收紧有效**（每趟 CROSS 仅几次）。
2. **loop 卡顿是真 bug 且已修复**——这比调参更重要，因为它让任何参数结果不可复现。
3. **算法管理器可用**（bb_fast/bb_18/bb_19 命名档生效并记进 PARAMS，方便 A/B）。
4. 但 BB 这套仍 **~20% 丢线、没裕量**，能跑完靠运气；`lograte10` 缓冲约 97s 写满看不到结局。

## 三、阶段② PID（log28-31）：外轮封顶 + 调 kp/kd

### 核心结构改动
PID 分支**外轮封顶在 base**（问题02 方案A）：修正量只减慢内轮（可反转），外轮不超过 base、绝不加速冲弯。

### 逐条要点
- **log28（未封顶，反例）**：kp80/kd15。对称差速 `base±output` 把**外轮顶到226(2.4×base)**——一边猛左转一边把速度拉到2倍多，直接冲过左弯半径→**遇第一个左弯~2s即飞**。kd15 火上浇油（output里一半是 kd 尖峰）。→ 结构问题，触发外轮封顶改动。
- **log29（封顶,同参数）**：外轮封顶96、不再飞、跑80s。但 **LOST 29.8%、欠转**：kp80 相对 base96 太低，边缘内轮=96−80=**16(仍正不反转)**，急弯转不过来→跑宽丢线→pivot找回。判定：欠冲。
- **log30（提kp过头）**：kp130/kd6。**LOST 52.3%、只跑16s、过转**：边缘内轮压到**−109(狠反转)**，差速205≈原地猛掰→掰过头甩出。直道仍稳。**重要更正**：LOST 92%在左**不是左右轮不对称，是赛道只有左弯**——以前所有"偏左"观察按此重解，不用查传感器对称性。
- **log31（最优）⭐**：kp80/**kd20**。**LOST 18.5%(所有跑最低)、80s无撞停、跑到129s、左右丢线均衡(699/819)**。机理=**kp80温和稳态跟随 + kd20进弯瞬间强反转pivot(内轮瞬时到−173) + 外轮封顶保证这股劲只转不冲**。"外轮封顶+高kd"是关键组合。

### 甜点定位
| kp | 内轮边缘行为 | 表现 |
|----|-------------|------|
| 80 (log29) | =+16，不反转 | 欠转、跑宽丢线 |
| 130 (log30) | =−109，深反转 | 过转、掰过头甩出 |
| **80 + kd20 (log31)** | 稳态温和，进弯 kd 尖峰狠反转 | ✅ 甜点 |

## 四、可复用的调参直觉（症状→参数）

| 症状 | 数据特征 | 参数问题 | 方向 |
|------|---------|---------|------|
| 冲飞、外轮>base | pwm 远超 base、~2s停 | 外轮未封顶(结构) | 封顶(已修) |
| 欠转、跑宽偏差大 | 内轮不反转(≈+16)、LOST高 | kp 相对 base 太低 | ↑kp / ↓speed |
| 过转、进弯猛掰甩出 | 内轮深反转(−100+)、时长骤降 | kp 太高 | ↓kp |
| 弯道跟不住但直道稳 | 进弯"该使劲不使劲" | kd 太低无预判 | ↑kd(配合封顶) |
| 进弯抖/毛 | err 快变尖峰 | kd 太高对噪声敏感 | ↓kd |
| 能跑完靠运气 | LOST 20%+ | 整体太激进无裕量 | 弯道降速/降speed |

## 五、当前最优基线 & 下一步

**基线（已存档 `algo_pid`）：`PID, speed15, kp80, ki0, kd20, slew5000, 外轮封顶`**
→ LOST 18.5%（最低）、80s 无撞停、左弯跟得住、左右均衡。

**继续压 LOST 到个位数 —— 一次只动一个，跑一趟看 LOST%：**
1. `kp 80→90` 小幅上探（弯道更跟得住？会否又过转）。
2. 或 `speed 15→13` 给裕量、过冲绝对幅度更小。
3. `kd` 保持 20，别再大幅加（噪声敏感）。
4. 想看完整 129s 一趟：临时 `lograte 15`（10ms 缓冲约 97s 写满看不到后半程）。

**已排除/已解决**：loop 卡顿(已修)、cross 误判(已收紧)、"系统性左偏"(实为赛道只有左弯，非硬件)。
