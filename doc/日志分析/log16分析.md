# log16 数据分析报告（PID 走直线，几乎不歪）

> 背景：切到 **PID 算法**（`algo=1`）跑直线，主观观感"一点也不歪"。本文用数据佐证，并与 bang-bang（log15）对比。
> 参数：speed=17, base≈108, **algo=PID**, pid_kp=40, pid_ki=0, pid_kd=5, slew_rate=5000。误差为加权位置 `err`（setpoint=0，正=偏右、负=偏左），记在每行最后一列。

## 一、结论：PID 直线跟踪非常稳，接近笔直

| 指标 | bang-bang(log15) | **PID(log16)** |
|---|---|---|
| 直线状态 | 3s 直行 + 有界小蛇形 | **全程贴中线连续微调** |
| 位置误差 | 会漂到边缘(CH6~CH8) | **全程 `err` ∈ [-0.33, +0.09]** |
| PWM 行为 | 有反转(-54)、发卡、大摆 | **稳在 108±15，无反转、无硬跳变** |
| 修正方式 | 离散档位硬跳 | **按误差连续微调，无死区** |

数据完全支持"一点也不歪"：**车头偏差始终被压在很小的范围内，左右轮只做小幅差速微调，没有任何一次大幅横摆或反转。**

## 二、数据证据

### 1. 误差全程很小
`err` 序列（跟踪段）：-0.14, 0, -0.10, -0.17, +0.06, +0.09, -0.30, -0.20, -0.32, -0.27, -0.22, -0.16 …
**始终在 ±0.33 以内**，绝大多数 |err| ≤ 0.2。相对满量程 ±1.0，等于车头一直贴着中线附近，从没真正偏出去。

### 2. PWM 平缓、无反转
左右轮 PWM 全程在 **74~127** 之间（绝大多数 98~118），差速通常只有 ±10~15：

| 行 | pattern | L/R | err | 说明 |
|---|---|---|---|---|
| 47 | `08`(CH4) | 103/113 | -0.14 | 微偏左，左轮略降修正 |
| 48 | `08` | 109/107 | +0.00 | 已回中，几乎对称 |
| 54 | `10`(CH5) | 98/118 | -0.20 | 小幅左修 |
| 62 | `08` | 101/115 | -0.16 | 持续小修 |

对比 log15 的 bang-bang，L/R 一度冲到 -54/108 那种反转大摆——PID 这里**完全没有**。这就是"不歪"的直接来源：连续小修正代替了离散大跳变。

### 3. 长时间稳态直行
多处出现 mode 保持上千毫秒才切换（行 49 dt=1359、行 53 dt=1378、行 70 dt=1195），期间 PWM 都是 108/108 附近，说明**大段时间车就是笔直地走**，只在极小偏差时轻点一下。

## 三、为什么 PID 这次成了

1. **连续按偏差修正、无死区、无硬跳变**：bang-bang 是"到某档才动、且一动就跳一大步"，天生有死区极限环；PID 对加权位置误差连续响应，偏一点点就修一点点，从根上避免了蛇形。
2. **软件延迟已去掉（slew=5000）**：PID 的小修正能**及时**下发到电机，不像之前 slew=600 那样爬半天（见 `log15分析.md` 第八节）。PID + 快 slew 是这次能贴稳的前提。
3. **Kd=5 提供阻尼**：微分项对误差变化率响应，能提前刹住，抑制过冲，让修正干脆不振荡。

## 四、终段丢线 = 轨道到头，非算法问题

行 71–78：pattern 从 `D0/D8`(CH8+CH7… 线快速移到最左) → `00` LOST_L → LOST_STOP；随后行 85–86 出现 `FF`（8 路全白）。这与之前几次一样，是**车跑到短轨道尽头、线移出视野后进入开阔白面**，属轨道太短，**不计入直线跟踪评价**。注意此前 `err` 只到 -0.33（并未失控发散），进一步说明是线消失、不是 PID 崩掉。

## 五、一个值得注意的小细节：轻微稳态偏置

即便"居中"，`err` 也常停在 **-0.1 ~ -0.16** 的轻微负值（偏左），而不是精确的 0。原因：`pid_ki=0`，纯 P+D **无法消除固定的小稳态误差**。这点小偏置可能来自传感器中心标定或轻微机械左偏（与之前"第一次漂总偏左"的观察一致）。
- 现在这点偏差极小，车看起来已经笔直，可不动。
- 若想把它也压到 0，可加**很小的** `ki`（如 0.5~2）消除稳态误差；但注意抗积分饱和，别加大了引入新的慢摆。

## 六、下一步建议

1. **直线已达标**，这套 PID 参数（kp=40, ki=0, kd=5, slew=5000）直线跟踪合格，可 `save` 固化。
2. **上弯道测试**：直线好不代表弯道够，重点看 kp/kd 在中小半径弯、发卡弯够不够劲、会不会切内/冲外，按弯道表现再调 kp（转向力度）和 kd（阻尼）。
3. **可选**：如需消除第五节的小稳态偏置，试加 `ki` 0.5~2；或按方向 2 实测左右轮传动比，从硬件上把中心做正。

## 七、一句话总结

切到 PID 后，直线跟踪从 bang-bang 的"有界蛇形"变成"**全程贴中线、误差 ±0.33 内、PWM 108±15 无反转**"，主观客观都是笔直。前提是 slew 已放开（软件延迟去掉）让小修正及时到位。终段丢线是轨道到头，非 bug。下一步转战弯道。
