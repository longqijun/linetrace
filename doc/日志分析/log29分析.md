# log29 分析（PID 外轮封顶修复后：不飞了，但欠转、偏差大）

> 背景：烧入"PID 外轮封顶 base"（问题 02 方案A）后重跑 PID。参数同 log28：**speed15, kp80, ki0, kd15, slew5000**（base≈96）。现象（用户）：能跑起来了，但**偏差太大，有时候原地打转又回到跑道**。

## 一、✅ 确认修复生效：外轮不再飙、不再飞
| | log28（修复前） | **log29（修复后）** |
|---|---|---|
| 最大 pwm_l / pwm_r | 飙到 **226** | **96 / 96（=base，封顶）** |
| 结局 | ~2s 遇左弯即飞、打转到停 | **跑了 80 秒** |

两轮 PWM 都封顶在 96=base，**转弯不再加速冲进弯**——log28 那个"外轮 2.4×base 冲飞"的结构问题**已解决**。车现在能持续跑（80s），"有时打转又回跑道"是**丢线后找线 pivot、然后重新压线**的恢复行为，不再是一去不回的飞出。**这是对的方向。**

## 二、但现在的问题：欠转、偏差大
统计：**LOST 占比 29.8%**（A=1566, B=882），比 BB 的 ~20% 还高；err 到过 -0.94。

原因：**kp=80 相对 base=96 太低，内轮转不够狠**。
- 封顶后，边缘(err=1)时：内轮 = base − kp = 96 − 80 = **16（还是正的，不反转）**，外轮 = 封顶 96。
- 这只是个**温和单侧转向**（内轮减到16、不反转），**急弯根本转不过来** → 车跑宽 → 线甩到边缘 → 丢线 → 原地 pivot 找线 → 再压回。
- 所以"偏差太大 + 原地打转又回跑道"= **欠转→跑宽→丢线→找回**的循环。和 log28 恰好相反：log28 是"外轮加速冲过头(过冲)"，log29 是"内轮不反转转不够(欠冲)"。

## 三、根因一句话
外轮封顶修好了"过冲冲飞"，但 **kp 相对 base 太低、内轮不反转**，导致弯道欠转、偏差大。**现在是调参问题，不是结构问题了。**

## 四、建议（按方案02"配合调参"）
1. **⭐提 kp 让内轮反转**：base96 → kp 到 **120~140**，边缘内轮 = 96−130 = **-34（反转）**，配合外轮封顶 96 = "内轮反转 + 外轮≤base"的强 pivot（正是 BB 发卡的思路）。这是当前最该做的。
2. **降 kd**：15→6~8，减少 err 快变时的抖动/尖峰（偏差大也可能有 kd 抖的成分）。
3. **可再降速**：speed 15→12/13，给欠转留裕量、偏差绝对值更小。
4. **左偏仍在**：LOST_L=1566 vs LOST_R=882，还是左多。先确认左右轮/标定是否对称（`log26-27分析.md` 第四节）。

## 五、下一步顺序
`pid kp 130`、`pid kd 6`（先不动 speed），重跑看：
- 急弯是否转得过来（内轮出现负值 = 反转）、LOST% 是否下降、偏差是否收小；
- 外轮应仍封顶 96（不会再超）。
不够再降 speed 到 12。

## 结论
外轮封顶（方案A）**结构上修对了**——不飞、能跑 80s。剩下的"偏差大/打转"是**欠转**，纯调参可解：**提 kp 到 120-140 让内轮反转** + 降 kd，再看左偏。
