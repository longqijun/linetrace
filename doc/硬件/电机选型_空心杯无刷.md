# 电机选型：空心杯 / 无刷（直驱）——巡线小车

> 目标：为巡线小车找响应更快的电机，解决"轮子换速慢一拍"的问题（见 `如何判断当前有没有机械延迟.md`）。本文汇总**中国**与**日本**两地的空心杯/无刷电机品牌与型号，附官网/购买链接。
> ⚠️ 链接与参数请以打开页面为准（型号、价格、库存会变）。链接均来自公开检索，非厂商背书。

## 一、先厘清一个现实：纯"无刷直驱、无变速箱"对巡线车不容易

- 你看到"人家没变速箱、直驱无极变速"，那类车多是**高 KV 无刷 + 轻车身 + 大轮**，靠转速换速度；但**直驱扭矩很小、低速控制难、易打滑**，起步和急弯容易掉链子。
- 竞速巡线/电脑鼠(Micromouse)圈子里，**主流其实是"空心杯/无刷电机 + 小减速比行星齿轮 + 编码器"**（如 Maxon DCX、Faulhaber、Namiki、Pololu HP），不是纯直驱。原因正是：空心杯/无刷解决"响应快"，小减速比（如 5:1~30:1）兼顾扭矩，编码器做闭环。
- **对你的情况**：你现在已是"有刷 + 可换减速比(114.7/38.2/12.7)"，**最低成本的一步其实是先降减速比 + 加编码器**（见机械延迟文档第七节），未必要立刻换电机。下面按"要不要换、换什么"分档给方案。

## 二、选型要看的关键参数

| 参数 | 说明 / 对巡线的意义 |
|---|---|
| 类型 | **空心杯(coreless)**：无铁芯、转子惯量极小→响应快、无齿槽顿挫；**无刷(BLDC)**：寿命长、功率密度高、需专用驱动 |
| 减速比 | 越小越快、响应越snappy(惯量∝比²)，但扭矩越小。巡线常用 5:1~50:1 |
| **编码器** | 做闭环速度控制的前提，能压左右轮不一致、减小 stiction 影响——**强烈建议带** |
| 额定电压/电流 | 与你电池方案匹配（你是 18650 双电源，见 `电池选型.md`） |
| 堵转扭矩 | 起步/急弯内轮反转要够劲，太小会"刹不住/掉不了头" |
| 尺寸/重量 | 越轻越好，车轻则惯量小、更好控（竞赛常限 30×30cm） |
| backlash | 齿隙越小换向越利索，直接影响急弯反转 |
| 驱动器 | 有刷用普通 H 桥(如 DRV8833/TB6612)；无刷需 ESC/专用三相驱动 |

## 六、给你的建议（按预算/投入分档）

1. **零成本先做（最推荐先试）**：先按机械延迟文档第七节**把减速比从 114.7:1 降到 38.2:1**，看响应是否够。这不用买电机，最快验证"慢一拍"到底还差多少。
2. **小投入、收益大**：给现有电机**加编码器**做闭环速度控制——直接治左右轮不一致和 stiction，比换电机更划算。国产 N20+霍尔编码器方案成熟便宜（微雪/DFRobot 链接见上）。
3. **要换电机（响应+精度都要）**：选**空心杯 + 小减速比(≤30:1) + 编码器**一体化方案：
   - 性价比：**兆威 ZHAOWEI** 或 **N20 空心杯+编码器**（国产，便宜、好买）。
   - 经典可靠：**日本 Namiki**（Micromouse 同款，贵一些但成熟）。
4. **冲竞赛顶配**：Maxon DCX / Faulhaber（贵、需配好驱动和电池），非必要不上。

> 我的顺序建议：**先降减速比(38.2:1) → 加编码器闭环 → 仍不够再换空心杯**。别一上来就买直驱无刷——扭矩和低速控制的坑更多。
