## 日志分析 — `日志分析/`
每份 `logNN.txt` 是抓取的原始数据，`logNN分析.md` 是对应分析。关键脉络（详见 [调试记录](调试/调试记录.md)）：

| 分析 | 结论要点 |
|---|---|
| [log13分析](日志分析/log13分析.md) | 老 bang-bang 从不进 STRAIGHT，居中被判 CROSS → 发散丢线 |
| [log14分析](日志分析/log14分析.md) | 改中心直行后仍漂；三根因（slew/找线反转/激进档） |
| [log15分析](日志分析/log15分析.md) | slew 600→5000 后直线不丢；**证明软件延迟是主因** |
| [log16分析](日志分析/log16分析.md) | PID 直线笔直，err ±0.33 内 —— **直线达标** |
| [log17分析](日志分析/log17分析.md) | 弯道 bang-bang 每弯必险；含**弯道降速方案A**详解 |
| [log18分析](日志分析/log18分析.md) | 方案A 第一版仍冲出；削弱了发卡内轮 |
| [log19分析](日志分析/log19分析.md) | 方案A 第二版（minpwm）按设计工作，但动不了 sharp/发卡 |
| [log20分析](日志分析/log20分析.md) | 跑最久 67s，但 sharpspeed 被 minpwm 吃掉无效；**软件到顶** |
| 早期 | [log4](日志分析/log4-分析报告.md)、[log5](日志分析/log5分析.md)、[log6](日志分析/log6分析.md)、[log10](日志分析/log10分析.md)、[log11](日志分析/log11分析.md)、[bangbang/](日志分析/bangbang/) |
